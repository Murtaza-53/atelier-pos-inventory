# Atelier Retail Inventory Dashboard

## Scope
Recreate the supplied inventory dashboard at `/` as a responsive, interactive frontend.

## Build
- Establish the light retail design system, typography, spacing, borders, shadows, and status colors.
- Build the collapsible sidebar, outlet status, full navigation, management callout, and sync footer.
- Build the top store controls, search, status indicators, new-sale action, notification, and profile area.
- Add the inventory heading, actions, navigation tabs, five KPI summaries, filters, and view switcher.
- Add all ten supplied inventory rows with filtering, selection, status indicators, pagination, and a toggleable product details panel.
- Add category progress, stock status donut, and recent movement summaries.
- Adapt the layout for smaller screens without losing core controls or table access.

## Interactions
- Search filters product name, subtitle, SKU, category, and brand.
- Category, brand, and status selectors filter the table.
- Clicking a product opens its details; the close control hides the panel.
- Inventory tabs, product-detail tabs, table/grid switcher, sidebar collapse, and pagination respond visibly.

## Validation
- Verify the production build.
- Check the running page at desktop and mobile sizes, including the major interactions and overflow behavior.
- Add unique inventory metadata for search and social previews.
